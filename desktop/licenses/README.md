# Bundled notice provenance

`victory-vendor-37.3.6.txt` is copied verbatim from the matching Victory v37.3.6 upstream tag:
https://raw.githubusercontent.com/FormidableLabs/victory/v37.3.6/LICENSE.txt

The npm package omits that top-level notice. The packager also includes its `lib-vendor/*/LICENSE` files and notices from production dependencies. Review this exception when updating victory-vendor; the build deliberately rejects a mismatched version.
