# Steam screenshot capture checklist

Manual captures only. Read [the shot plan](STEAM_SCREENSHOT_PLAN.md) for context.

## Before starting

- [ ] Use the verified v0.1.9 Windows package and an exported real career; keep the original export unchanged.
- [ ] Launch the isolated capture command; verify its printed dimensions. Check the final PNG is exactly 1920 × 1080 (or a consistently chosen higher native 16:9 size). Windows scaling can change actual pixels.
- [ ] Use standard text size/dark theme; keep side navigation visible. Dismiss guide explanations through normal UI in the copy.
- [ ] Close dialogs, pause Auto Play for stills and wait for history/loading to finish. Do not hide warnings with CSS or edit outcomes.
- [ ] Capture only game content. No desktop/taskbar/titlebar, private paths, diagnostic panels, promotional overlay or cursor over text.
- [ ] Save originals directly under `release/steam/screenshots/`; no illustrative mockups. Review at full size and reduced store-view size.
