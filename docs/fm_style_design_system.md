# FM-Style Design System

## Visual Direction

The game should look like a premium sports management dashboard inspired by Football Manager, but not a copy.

The UI should be:

- Full width
- Desktop-first
- Data dense
- Dark mode by default
- Professional and clean
- Built around tables, cards, panels and tabs

## Layout Structure

Every main game screen should use this layout:

1. Top status bar
2. Left sidebar navigation
3. Main content area
4. Right context panel where useful

## Top Status Bar

The top bar should show:

- Current date in game
- Player name
- Current ranking
- Cash balance
- Form
- Confidence
- Next tournament
- Inbox/messages icon
- Continue button

Example:

Date: 14 May 2028  
Player: Ryan Taylor  
Ranking: Amateur #12  
Cash: £4,250  
Form: Good  
Confidence: 72  
Next Event: Q Tour Event 3  
[Continue]

## Left Sidebar Navigation

Main navigation:

- Home
- Player
- Training
- Coaches
- Finance
- Equipment
- Calendar
- Tournaments
- Rankings
- Match Centre
- Sponsorship
- Stats
- Legacy
- Inbox

## Main Content Layout

Use a 12-column grid.

Common layout:

- Main panel: 8 columns
- Right panel: 4 columns

Alternative data-heavy layout:

- Full-width tables
- Filters above table
- Detail drawer or modal on row click

## Colour Style

Use a dark slate/navy background.

Suggested colours:

- Background: #0f172a
- Panel: #111827
- Panel lighter: #1f2937
- Border: #334155
- Primary accent: emerald/green
- Secondary accent: gold
- Danger: red
- Warning: amber
- Text: white / slate-200 / slate-400

## Component Style

Use:

- Rounded cards
- Thin borders
- Compact tables
- Small stat badges
- Progress bars
- Attribute bars
- Tabs
- Filters
- Sortable columns
- Status pills

## Typography

Use a clean sans-serif font.

Hierarchy:

- Page title: large and bold
- Section title: medium and bold
- Table text: compact
- Labels: small uppercase
- Numbers: clear and prominent

## UI Priorities

The interface should prioritise:

1. Player status
2. Next decision
3. Career progression
4. Financial pressure
5. Attribute development
6. Tournament progress

Every screen should answer:

- What is happening now?
- What decision does the user need to make?
- What has changed since last week?
- What is improving or getting worse?
