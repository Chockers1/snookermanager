# Snooker Career Manager - Game Design Brief

## Core Concept

Snooker Career Manager is a full-screen Football Manager-style sports management game where the user creates and manages one snooker player's entire career.

The user does not directly play shots. Instead, they manage training, attributes, coaches, finances, equipment, tournaments, rankings, sponsorships, form, confidence, match tactics, and career progression.

The career starts at youth level and progresses through:

1. Junior club snooker
2. Regional youth events
3. National youth events
4. Amateur circuit
5. Q Tour / Q School
6. Professional tour
7. Elite professional career
8. Veteran stage
9. Senior tour / retirement

## Main Gameplay Loop

Train player → Improve attributes → Enter tournaments → Simulate matches → Earn money → Upgrade coaches/equipment → Climb rankings → Unlock bigger events → Build legacy.

## Game Style

The interface should feel like Football Manager:

- Full-width desktop layout
- Dark professional sports dashboard
- Left sidebar navigation
- Top status bar
- Dense data tables
- Cards, tabs, charts and stat panels
- Minimal wasted space
- Designed for long play sessions
- Information-rich but clean

## Key Systems

- Created player career only
- Attribute development
- Weekly training planner
- Coach hiring and upgrades
- Finance and budgeting
- Cue, chalk and tip equipment system
- Tournament calendar
- Ranking system
- Match simulation
- Form, confidence and mental state
- Sponsorship and reputation
- Career stats and legacy
