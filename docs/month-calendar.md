# Tournament month view

Open Tournament Calendar and select Month view. List view retains season strategy, qualification, travel and entry planning.

The Monday-first calendar fills the available game panel. Tournaments appear as bars spanning their inclusive start/end dates. Bars wrap across weeks, show continuation arrows at clipped boundaries, and use separate lanes for overlapping events. Busy weeks scroll internally so all tournament buttons remain accessible while the whole month stays visible.

Previous month, Next month and Today navigate consecutive months, including empty months and year boundaries. Tour filters distinguish junior, amateur, Q Tour, Q School, main-tour and seniors/exhibition events. Specific circuit narrows those further to regional circuit labels. Filters carry between views; choosing a different tour clears the circuit filter.

Click a tournament for its existing event details and entry/travel controls. The modal supports Escape, a close button, backdrop dismissal and keyboard focus containment. The game date is highlighted and entered events carry a tick. This uses the current season's generated schedule; months without scheduled events show an empty calendar.

Validation covers leap years, four/five/six-week months, cross-month/year spans, overlapping lanes, filters, empty-month navigation, event details and responsive screen fit, using isolated browser saves.
