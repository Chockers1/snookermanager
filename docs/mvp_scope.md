# MVP Scope

## Version 0.1 Goal

Create a playable browser-based MVP of Snooker Career Manager.

The player should be able to:

1. Create a snooker player
2. View their career dashboard
3. Train each week
4. Improve attributes
5. Hire coaches
6. Buy cues, chalk and tips
7. Manage money
8. Enter tournaments
9. Simulate matches
10. Earn prize money
11. Move up rankings
12. Track career stats

## Do Not Build Yet

Do not build these in v0.1:

- Multiplayer
- Academy/stable management
- 3D snooker physics
- Real licensed players
- Online saves
- Complex media system
- Full senior tour
- Deep sponsorship negotiation
- Real-world brand names

## MVP Screens

Build in this order:

1. App shell
2. Career dashboard
3. Create player
4. Player attributes
5. Training planner
6. Finance dashboard
7. Coach market
8. Equipment shop
9. Tournament calendar
10. Match simulation
11. Rankings
12. Career stats

## MVP Match Engine

Use a simplified simulation based on:

- Player technical attributes
- Mental attributes
- Fatigue
- Confidence
- Opponent strength
- Equipment bonuses
- Coach bonuses
- Tactical approach

The match engine should produce:

- Final score
- Frame results
- Highest break
- Number of 50+ breaks
- Number of centuries
- Confidence change
- Fatigue change
- Prize money earned
