This release makes the career interface easier to navigate, with screen-height layouts, clearer comparisons and separate views for detailed records. Save Manager now distinguishes the career you are playing from another selected save or a recovery snapshot.

### Career and competition screens
- Redesigned Rankings, Tournament Calendar, Tournament Hub, Match Preview, Mental, Health and Season Review around focused tabs and internally scrolling content.
- Reworked Rivalries with a searchable opponent list, head-to-head summaries, intensity and close-match records, plus separate meeting history and explanation tabs.
- Moved attribute display and history controls into one consistent row, including older-save recovery. Attribute precision is retained in the save while displayed values remain readable.
- Made the season review use the closing world-ranking table when available.

### Training editors
- Redesigned Development & Practice, Form Assessment and Training Base dialogs with clearer status, choices, evidence and costs.
- Separated form assessment and recovery choices from the recorded match-evidence view.
- Training Base compares facility fees, session limits and efficiency alongside location strengths and trade-offs. The confirmation summary shows joining and relocation costs, recurring fees and remaining cash.

### Save management
- Shows the active career, player, game date and autosave destination prominently.
- Selecting another career previews it; opening it is a separate action. Named careers can be renamed without changing their player or saved progress.
- Copy creation identifies its source and explains that the new copy becomes active while the original remains available.
- Automatic backups default to the active career and show career names and references to distinguish similar saves.
- Import and export have a dedicated tab that identifies the active export source and explains that imports create a separate career.

### Validation
- All 927 unit tests across 89 files passed with two workers. The initial unrestricted run exceeded several test timeouts under parallel load; the complete rerun passed with unchanged timeouts.
- Targeted browser checks passed for the redesigned screens, desktop and mobile layouts, enlarged text, keyboard controls, decimal formatting and player links.
- Save checks covered renaming, copying, switching, reload, invalid import rejection, backup rotation, corrupt backup rejection, restore as a copy, protected season rollover and changes made during background saving.
- TypeScript, production build and lint passed. The versioned release build was checked again after updating the manifest.
- No new multi-decade simulation was run for this interface release.
