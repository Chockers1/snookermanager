This release makes Match Preview scouting, Health treatments and desktop navigation fit more comfortably on screen. It adds a sixth treatment with a distinct recovery tradeoff.

### Match Preview scouting
- Replaced the attribute table with six cards in three columns and two rows on desktop.
- Grouped your rating, the opponent's estimated range and the estimated edge, retaining two-decimal formatting.
- Compacted the scouting explanation and summary so the comparison and recent opponent results remain visible at tested desktop sizes, including 130% text.

### Health treatments
- Redesigned treatment selection as six cards with clear prices, recovery figures and selection state.
- Kept the selected treatment's description, exact before-and-after effects, remaining cash and confirmation together.
- Added Sleep & Recovery for £90: up to 18 fatigue, 6 strain and 14 burnout relief, without reducing injury time. Recovery remains capped at the player's current load.
- Preserved treatment affordability checks, follow-up restrictions and protection against repeated charges after reloading.

### Desktop navigation
- Adjusted sidebar spacing to the available window height so every menu item, including Season Review, stays visible at tested desktop sizes without scrolling.
- Preserved enlarged text, keyboard navigation and the mobile navigation drawer.

### Validation
- All 931 unit tests across 89 files passed.
- All 14 release browser checks passed for scouting, treatments, desktop sidebar fit, keyboard access and recovery effects; the mobile drawer keyboard check also passed during development.
- TypeScript, production build and lint passed.
- No new long-career simulation was run for this interface and treatment release.
