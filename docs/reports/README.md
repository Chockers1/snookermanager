# Canonical Reports

This directory contains the compact reports used to document and review the current game balance. Raw simulation JSON, per-run Markdown, CSV rows, debug traces, and player snapshots are generated in `artifacts/simulations/` and are intentionally excluded from source control.

The primary balance conclusion is recorded in `30-year-e2e-all-starts-ai-summary.md`. The remaining audit reports cover calendar integrity, tournament formats, player event volume, ranking points, match accounting, status integrity, and CPU-player progression.
