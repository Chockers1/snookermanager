# Rules for VS Code / Copilot

## Build Rules

- Build one phase at a time.
- Do not create backend code yet.
- Do not introduce databases yet.
- Do not use real snooker players or real brands.
- Use mock data first.
- Keep components reusable.
- Keep styling consistent with the screenshots.
- Prefer clear code over clever code.
- Do not overcomplicate state management early.
- Use localStorage only when save/load is needed.
- Avoid building systems that have not been requested yet.

## UI Rules

- Desktop-first.
- Full-width layout.
- Dark theme.
- Left sidebar always visible.
- Top status bar always visible.
- Use dense but readable cards and tables.
- Use emerald and gold accents.
- Use compact spacing like a sports management game.
- Every screen should show the current player context.

## Game Design Rules

- Single created-player career only.
- No academy mode.
- No multi-player stable management.
- The core loop is:
  Train → Improve → Enter Events → Sim Matches → Earn Money → Upgrade → Climb Rankings.
