# Screenshot Reference Guide

These screenshots define the intended UI direction for Snooker Career Manager.

The game should use a full-width, Football Manager-inspired desktop layout with:
- Dark navy/slate background
- Left sidebar navigation
- Top status bar
- Dense data tables
- Stat cards
- Progress bars
- Tabs
- Right-side context panels
- Emerald and muted gold accents
- Professional sports management dashboard feel

## Build Instruction

When implementing each screen, match the screenshot layout and visual hierarchy as closely as possible while keeping the code modular and reusable.

Use shared components for:
- App shell
- Sidebar
- Top status bar
- Stat cards
- Data tables
- Attribute bars
- Progress bars
- Tabs
- Detail panels
- Status badges
- Action buttons
