# New-season Tour Changes message

Starting a new season sends a separate Tour Newsdesk message titled [season] · Changes around the tour. It complements the player's own season briefing and tournament invitations.

The report compares the closing world population and senior field with the fully populated new season. It records retirements, new senior-field members, Q School graduates and requalifying professionals, other newly awarded professional cards, new under-21 prospects, new adult pathway players, and non-retired players losing cards. The human player's own career is covered by the existing season briefing. Simply turning 40 is not treated as a senior-tour move, and already retired players are not announced again.

Counts cover every recorded change. Each category initially highlights two names, with the remaining names available in an expandable list. Names, ages, nations, qualification routes and recorded career achievements are frozen in the saved message. A senior arrival can also be listed as losing a professional card.

The completed report is captured during rollover after the new world population is generated. Delivery waits until the user starts the new season. A persistent season marker prevents duplicate announcements after save/reload, repeated start actions or inbox trimming. Archived messages keep their original snapshots.

Existing saves without the original population comparison can receive a clearly labelled partial report from retained previous-season profiles and dated recruit IDs. Missing intake data is not fabricated or reported as a confirmed zero. New careers do not receive invented pre-career changes.

Validation covers transition classification, Q School requalification, quiet seasons, legacy partial coverage, immutable messages, duplicate prevention and real rollover. Browser checks cover desktop/mobile layout, expanded intakes, separate message selection, accessible actions and reload.

Tour news uses the standard inbox message list, heading, reading pane and action buttons. Its categories appear as stacked report-summary sections with expandable names, rather than a separate full-width dashboard.
