# Snooker Career Manager asset pack

The supplied 1672x941 artwork is treated as the current key art/promotional composition, not one exact Steam asset. This pack recomposes it into the required aspect ratios.

The project structure intentionally uses `public/assetts` to match `C:\dev\snooker_career\public\assetts`.

Included: brand PNG/SVG files, working 6000x4000 promotional master, 4K title-free background, Steam store and library assets, desktop/web icons, in-game art, marketing graphics and achievement templates.

Screenshots and trailer are not fabricated from artwork: their folders contain the exact capture plan because Steam expects real game footage/screens.

Quality note: the source supplied was 1672x941. Larger files are high-quality resampled working exports; replace the source with a native 4K/6K render later if one becomes available.
